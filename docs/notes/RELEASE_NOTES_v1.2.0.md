# myDeepSeek v1.2.0

界面按 Material 3 补齐，流式 Markdown 渲染按上游策略重做，并修掉一类会让 App 直接退出的缺陷。

## 改进

- **流式出字更顺。** 逐字显示改成按真实帧间隔分配（约 60 字/秒，积压自动追赶），一帧被拖长只短暂让出、不再"卡一次停两秒"；内容追平后彻底挂起，不再空转轮询。系统关闭动画时直接显示全文。
- **带公式的回复不再重播。** 一段回复被公式切开时，逐字进度由整条回复共用，公式后面那段不会先消失再重新长出来。
- **普通段落渲染更轻。** 流式尾块若是没有语法的单行段落，绕过 Markdown 库直接排版（字号、行高、对齐与库同源，定稿时版式不变）。
- **长回复打开更快。** 打开会话时的预热覆盖长消息（只预热首屏要用的块，有字符上限、可取消），不再把解析推回主线程。
- **代码块折叠恢复正常。** 代码块不再套"高度只增不减"，点「收起」会真的收回去。
- **界面按 M3 补齐。** 圆角阶梯统一为 8/12/16/24/28；对话顶栏 64dp、动作为填充式圆形图标按钮；空态图标加 96dp 色块底座；设置页改为大标题顶栏、主色分组标题、24dp 卡片与行间连接缝。
- **新的加载指示器。** 等首个 token 与切换会话时统一使用会变形的容器 + 轨道点（按 Material 3 Expressive 的 contained loading 形态绘制，当前依赖的 material3 版本未提供该组件）。

## 修复

- **重试 / 重新生成 / 续写 / 删除消息 / 从这里新建 / 切版本**，以及抽屉里的**重命名 / 置顶 / 删除**：这些操作此前遇到数据库或磁盘异常会直接结束进程（协程异常没有被收口）。现在统一转成一条提示，界面其余部分照常可用；续写失败还会把消息从"正在生成"退回原状态，不再出现删不掉、切不走的卡死消息。
- **对话内消息索引**在切版本 / 重新生成后（条数不变但消息变了）会指向已不存在的消息，点一条跳到错误位置 —— 已修正为按路径版本重建。
